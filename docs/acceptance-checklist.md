# 关键场景验收清单

维护日期：2026-09-29。用于后续任务选择受影响场景，**不是声称本轮全部执行通过**。实际结果写 current-status / CHANGELOG，生产发布证据写 deployment。仅使用隔离测试库；不要按清单在生产创建测试人员或场次。

## 认证与多岗位

- [ ] 未登录访问保护页跳登录；强制改密用户无法使用业务动作。
- [ ] 校验失败保留用户已输入资料，密码不回显到日志或文档。
- [ ] 重置、本人改密、离职使旧会话按规则失效；旧页面提交也拒绝。
- [ ] 老板不能自我离职/撤销老板身份；两个老板并发修改仍至少一位在职。
- [ ] 员工多选岗位显示一致，列表筛选包括兼任；新增岗位保留绑定。
- [ ] 中控+导粉可以同时执行本场与认领其他场；纯中控不能读取任何统计。
- [ ] 中控+运营、老板+其他岗位、负责人+中控的边界按最新确认单独验收，不能仅测纯岗位。

## 账号、交接与流程

- [ ] 中控必填，运营/主播可空；无主播档案可保存，但当前开始准备要求绑定主播。
- [ ] 普通员工看不到其他负责人的当前资料；账号历史不泄露当前实名/号码。
- [ ] 公司调拨保留原场次/报告归属；旧人员只能看原范围历史。
- [ ] 准备或直播中的账号拒绝交接/停用；旧编辑版本不能覆盖新版本。
- [ ] 主播详情可定位其具体账号，修改该账号运营/中控不影响其他账号。
- [ ] 三阶段事项鼠标拖动和上下按钮保存后顺序正确；跨阶段/取消拖动不误移。
- [ ] 定时分钟+秒正确，口令事项不设硬提醒；复制保留时间和顺序。
- [ ] 批量配置所有目标权限/版本一起检查；任一冲突整批失败，无部分覆盖。
- [ ] 已建场次的快照与进度索引不因账号流程修改变动。

## 一次上班到收尾

- [ ] 开始上班后可检查设备；跨零点仍同一上班，第一场提前分钟算正确。
- [ ] 同登录人不能同时两条未结束上班；到岗补填有原因、无重叠。
- [ ] 声音/画面/网络未正常不能开播；修复后可重新检查，变更有历史。
- [ ] 开始准备立即建场次；同账号不能重复准备/开播。
- [ ] 默认实际中控本人，可选同公司在职员工；选择代控不授予新访问权。
- [ ] 登录人、实际中控、账号的同时直播与时间重叠均受保护。
- [ ] 未正常开播必须原因+截图，保留记录且不能认领导粉。
- [ ] 点击任务完成记录时间；仅备注更改不重写完成时间；异常/不适用需要原因。
- [ ] 提醒时间正确、无声音、不阻挡、同时间合并，关闭不算完成、过时可补做。
- [ ] 话术复制可用；场中编辑同时更新本场和账号，其他历史快照不变。
- [ ] 异常中断、违规需要截图；普通下播未做完直播项需说明。
- [ ] 下播后处理所有收尾项、违规与异常确认才可完成；无统计填报要求。
- [ ] 可准备下一场再补前场；所有未完成执行处理后才能结束上班。
- [ ] 更正时间/实际人/任务/违规必留原因和前后值，不绕过时间重叠或归档状态。
- [ ] 未开播归档更正不变成真实已播，真正重开建立新场次。

## 截图

- [ ] PNG/JPG/WebP、数量/大小限制执行在服务端，非法类型拒绝。
- [ ] 未登录和无历史权限者无法直接读取图片URL；不在public目录暴露。
- [ ] 修改失败不留错误关联；清理只针对未引用的新文件；旧图追加不覆盖。
- [ ] 截图历史完整入口不受最近200条执行日志显示截断影响。

- [ ] 准备/取消/未开播不出现；新实际开播的LIVE/WRAP/COMPLETE可认领，旧资格false和已有历史报表不重复认领。
