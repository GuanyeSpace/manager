# 抖音账号管理：已确认范围与后续事项

确认日期：2026-09-07。

## 本阶段

- 账号字段：抖音号、账号名称、主页链接、实名人、绑定手机号、用途、备注。抖音号唯一；名称、分公司、中控必填，其他资料可后补。
- 一个账号同时归属一家分公司。仅老板可跨公司调拨，调拨时重新确认接收公司的人员。
- 运营、中控、主播每项职责最多一人；中控必填，运营和主播可为空。选取本公司对应岗位的在职员工，老板可兼任。
- 分公司负责人是分公司上的额外管理身份，不替换员工岗位。老板可兼任多家公司的负责人。指定、撤销负责人仅限老板。
- 老板可管理全部账号；分公司负责人可管理本公司全部账号；其他在职员工仅可查看本公司内自己当前绑定的账号。
- 每次修改保存历史版本和归属、人员姓名快照。旧负责人只保留本人负责期间的历史查看权，即使账号已调拨到其他公司；不展示当前资料和后续历史。
- 历史版本不保存实名人、手机号、主页链接、用途、备注或登录凭证。当前阶段历史展示账号名称、抖音号、分公司、人员、启停状态、版本起止时间和操作人；直播历史数据尚未接入。
- 分公司负责人按当前管理权限查看本公司历史；负责人身份撤销后，不再拥有该管理权限，个人曾负责的记录仍按个人身份可见。
- 账号不提供物理删除。启停仅为管理系统内状态，不操作抖音平台。
- 员工离职、调离分公司或改为不再兼容的岗位前，必须先交接所绑定的账号（包括停用账号）及分公司负责人身份。
- 停用分公司下的账号可查看，重新启用分公司后才能维护。
- 版本校验防止旧表单覆盖最新编辑；账号修改、历史、审计同事务提交。账号变更、负责人设置和人员变更共用管理锁。

## 使用入口

所有岗位工作台 → 抖音账号（`/accounts`）；历史记录（`/accounts/history`）。
老板工作台 → 分公司管理 → 指定负责人。

新建账号前先创建分公司及人员；中控尚未到岗时可选择老板。

## 后期自动化（本次不实现）

- 数据来源限定「直播服务平台·主播版」及普通抖音开放平台接口。
- 先验证真实账号可获得的数据字段、更新频率、历史范围和授权条件，再确定统计指标。
- 目前通过官方网页查看直播数据，本系统暂不提供登录、代登录或数据采集。
- 公司指定设备负责开播和发布作品；员工个人设备不登录抖音。员工在管理系统看统计数据。
- 后续统计凭证仅保存在服务器并由服务器使用，不能通过页面、接口响应、导出、日志或历史向员工提供。
- 普通扫码授权不等于获得主播版所有直播数据；Cookie 保存也不等于持久授权。接入前单独验证。
- 未来直播记录应按发生时间对应当时分公司与职责区间，交接不能重新归属既有数据。
