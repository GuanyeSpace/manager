## 字段与计算

- 开播时间：北京时间，按 UTC 入库。精确到分钟。
- 时长：小时、分钟、秒，内部保存总秒数。
- 场次：文字名称，例如早上场、下午场、晚上场；允许其他名称。
- 指标：曝光人数、进房人数、平均在线、最高在线、人均停留（分钟，最多两位小数）、评论人数、点赞次数、新增粉丝、分享次数、本场新增粉丝团人数。
- 进房率 = 进房人数 / 曝光人数 × 100%；新增率 = 新增粉丝 / 进房人数 × 100%。展示两位小数，分母为零显示“—”。不保存独立比例，避免与原始数字不一致。
- 未填不等于零。人数和次数为非负整数，平均在线不能大于最高在线，时长必须大于零，结束时间不能晚于当前时间。
- 不根据四舍五入后的后台曝光人数强制限制进房率，也不把不同场次观看人数的相加解释为去重观众。

## 使用

- 中控工作台 → 录入本场直播数据 / 查看直播数据。
- 老板工作台 → 直播数据，可按账号和日期筛选，逐场查看。
- 账号详情 → 查看此账号直播数据。
- 列表按开播时间倒序，每页 30 条。日期筛选包含结束日期整天，使用北京时间。
- 更正指标：打开详情，页面下方更正。账号和开播时间保存后固定，提交前务必核对。
- 同一账号、同一开播时间仅一条，重复提交会提示已有记录。并发更正使用版本号检测冲突。

## 权限与归属

- 当前负责中控可录入自己负责且启用的账号，老板可录入所有启用账号。
- 普通运营、主播仅能查看本人负责期间的记录，不能录入或更正；分公司负责人可查看本公司记录，不因管理身份自动获得录入权。
- 中控只能更正本人录入、本人负责期间且当前仍由本人负责的记录。老板可更正所有记录。
- 记录按开播时间匹配账号历史版本，保存当时的账号名称、抖音号、分公司及人员归属。账号调拨或改名不改变旧数据。
- 新中控不能通过当前账号权限查看前任负责期间的数据；前任可查看此前历史，不能继续更改或访问后续场次。
- 建档前的旧数据无法自动推断真实归属：仅老板在明确勾选确认后可补录，使用账号最早建档版本的归属，并标记为历史补录。归属不符时不要勾选，应先核对业务事实。
- 录入前在事务内重新校验会话、人员及账号权限，与交接共用管理锁。写入与审计同事务，审计包含更正前后指标。

## 每场变现数据（2026-09-08）

- 列表增加“直播间数据 / 变现数据”视图，共用账号和日期筛选。在已有场次详情中单独补填或更正，不重复录入账号、日期和场次；场观人数沿用进房人数。
- 中控填进粉丝群人数、链接点击人数、长按人数、后端加入人数、有效人数。支持分次补填，空值与 0 分开记录；有效人数不能大于已填写的后端加入人数。
- 用户确认：长按是打开卡片二维码后，长按识别进入添加微信步骤；后端加入为最终加入人数，有效人数为其中审核通过、用于打粉结算的人数。
- 带货情况区分尚未统计、没带货、已统计 GMV（可为 0）。GMV 暂按人民币元，使用 Decimal(14,2) 精确保存，不直接当作收入；打粉单价、佣金及结算暂未实现。
- 自动比例：进群率 = 进群/场观；点击率 = 点击/场观；群加入率 = 后端加入/进群；场观加入率 = 后端加入/场观；有效率 = 有效/后端加入。
- 用户已确认的公式：长按率 = 长按/点击；长按加入率 = 后端加入/长按；点击加入率 = 后端加入/点击。页面显示计算口径。分母为零或任一原始值未填写时显示“—”。
- 变现部分由当场中控且目前仍负责该账号的人或老板填写，即使直播间数据由老板代录，中控也可补填变现数据。交接后历史只读，沿用已有查看权限。
- 与本场其他数据共用版本号，防止并发覆盖；变现修改保存前后审计。更新直播间数据不会清除变现数据，反之亦然。

## 删除与回收站（2026-09-17）

- 直播列表、变现列表与详情/场次同页增加删除入口，删除前须核对范围并勾选确认。删除是设置时间标记，不物理删除指标、账号历史或工作场次。
- 删除直播数据后，该场直播与关联变现从正常列表隐藏；单独删除变现不影响直播指标。回收站按原权限展示，可恢复原值。先单独删除变现、再删除直播时，恢复直播不会擅自恢复此前单独删除的变现。
- 权限沿用维护规则：老板可处理全部，当前中控只能删除/恢复自己有权维护的记录；运营、分公司负责人不因能查看而获得删除权限。交接后的历史记录仍可查看，原中控不再有维护权限。
- 删除和恢复与保存共用管理锁、版本检查及事务审计；旧页面不能覆盖删除状态。已删除的相同账号/开播时间记录需恢复后更正，不重复建档。
- 工作流程和完成记录保留；工作台标识已删除的数据，并在原场次内提供恢复入口。
- 增量迁移 `20260917010000_report_recycle` 仅新增两个可空时间字段，不改写已有指标。隔离库测试覆盖范围、权限、指标不变、恢复顺序、并发重复操作、事务回滚、旧页写入保护及真实 HTTP 回收站渲染。
