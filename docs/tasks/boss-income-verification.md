# D057 老板收入概览与账号筛选验收

日期：2026-10-03。范围：只读首页与筛选；无schema、迁移、依赖或写服务改动。

## 实现与口径
- 老板首页保留三个运行概览，移除截图中五个快捷卡片，增加确定打粉数据收入。
- 默认全部主播、本月至昨天；支持日期快捷项、自定义日期、日/周/月和内部/外部主播。
- 总收入按有效数×后端单价整数分汇总；不是主播提成，无记录日期不补造零，软删除不计入。
- 账号支持中控、主播、状态、名称/抖音号组合筛选，可选择未分配；封禁不归入停用。人员选项只来自有权查看的账号。
