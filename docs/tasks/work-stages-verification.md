## 实现边界

- 开播前选择人员一次确认即建场；已选人员通过修改入口更新，开播后锁定。
- 三阶段任务只勾选/取消并显示成功时间；保存时互斥串行，服务端版本冲突拒绝覆盖。历史备注和异常/不适用保留，新开播与收尾只认done。
- 开播前严格全部完成；正常下播不要求完成直播任务。异常下播原因/截图必填，收尾自动带入。
- 下播后统一异常类型（违规/其他）和说明；收尾事务同时写标记、证据及状态。历史新增标记为null，不推断原异常类型。
- 未正常开播保留必填原因/截图；预计恢复日期不再输入，旧记录保留。截图父目录权限仅定向修复，文件权限不递归放宽。
